# QueryQuest

A mobile-first SQL learning & execution platform with Duolingo-style learning and interactive SQL playground. Vibe coded because my sister asked for it! ✨

## Features

- Progressive lessons from basics to intermediate
- Interactive exercises and challenges
- Safe SQL execution sandbox
- Gamification (XP, streaks, badges)

## Tech Stack

- Mobile: React Native + Expo
- Backend: Node.js + NestJS
- Database: PostgreSQL + Prisma

## Getting Started

```bash
npm install
npm run db:migrate
npm run dev:api
```
